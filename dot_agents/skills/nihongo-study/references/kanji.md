# 流程A：查汉字（kanji.md）

模拟用户手工操作：google `<汉字> かんじ` → 第一个看 kanjipedia.jp。

## 0. 输入解析（先做这步）

- 输入形如「X かんじ」（如制 かんじ / 掴 かんじ）：调查对象永远是第一个汉字 X，「かんじ」二字是検索タグ，直接丢弃。かんじ≠感じ，禁止解释成感じ。
- 动手前先复述一行：`調査対象：X`，然后输出必须以 `# 漢字：X` 开头。

## 步骤

1. 用 `websearch "<汉字> かんじ"` 找 `www.kanjipedia.jp/kanji/*` 链接。
2. `webfetch` 该页，提取以下字段（kanjipedia 页面结构固定）。证据分级：
   - `[fetch必填]` `音 / 訓`（`* 音` `* 訓` 行）、`意味`（`意味 ①… ②…`，照抄编号，不合并）、`下つき` 熟語一览。fetch 不到写 `—`，不许估、不许编。
   - `[可估]` 漢検級 / JLPT目安：仅当页面有依据才写，否则写 `—` 并加「目安」二字。
   - 忽略：`なりたち`（字源，除非用户问）、`上つき`（以该字开头的词太多，默认不列）
3. 全量历史层必读 `references/etymology-tree.md` + `references/history-phonology.md`，另起并行检索語源（語源由来/kotobank日国大/漢字源）。输出分四级 `[確定]/[通説]/[諸説]/[助記]`，多源不并线。
3. 找不到 kanjipedia 页时降级（表外漢字・国字如峠働はkanjipediaに無いのが正常）：`jisho.org/search/X%20#kanji` → `kakijun.jp` → `weblio漢和`。jisho 覆盖 kokuji（Kunのみ・音なし），音缺失写 `音：—` 不编。
4. 検索なしの出力禁止：一次 websearch/webfetch 都没做就不许输出。先检索，后写作。

## 熟語筛选规则

- 只留 6-10 个：优先二字熟語 + JLPT N5-N2 常见 + 新闻常用。
- 每个必须带假名读音 `[fetch必填]`。不知道读音不许编，查 weblio/goo 补，查不到该熟語弃用。
- 每个熟語尽量对应回 意味①②③ 中的某一条（例：`制限`→意味②おさえる）。

## 基本信息行

一行给完，不展开：`音[fetch] / 訓[fetch] / 漢検級[fetch无则—] / 画数[fetch] / JLPT目安[可估，无依据则—]`。

## 例文规则

- 2 句，用到该汉字或其核心熟語。
- 日语 + 假名注音（难读处）+ 中文一行对照。
- 一句偏日常，一句偏 JLPT/书面。
- 不自然な創作例文禁止。定番コロケーションのみ使う（例：×生き生きとする → ○生き生きとしている）。

## 出力雛形（この形で出す。例は下、形はここ）

```markdown
# 漢字：X
音：〜[fetch] 訓：〜[fetch]（画数[fetch]・漢検[fetch无则—]・JLPT目安）
核心一句话：…（中文，如轮到谁/第几轮）
意味[fetch原文番号維持]：
① …「例熟語」
② …「例熟語」
語源[確定/通説/諸説/助記]：…（1-2行）
音史：呉音/漢音/慣用+相关音变一行，无则—
語義樹：ASCII树+每步为何引申一句
熟語[fetch+读音核对]：A（読み） B（読み） …
例文：
1. 日语句 — 中文一行
2. 日语句 — 中文一行
記憶圧縮：…（5行内小树）
来源：本次检索到的真实URL（先贴URL再写作，无URL不输出）
```

## 例（制・形式見本。丸写し禁止）

```markdown
# 漢字：制
音：セイ 訓：おさえる（画数8・実測例）
意味（kanjipedia原文番号を維持）：
① おさえる。やめさせる。「制限」「制止」「規制」
② おさめる。したがわせる。「制覇」「制御」「統制」
③ とりきめる。さだめる。「制定」「制度」
④ おきて。きまり。しくみ。「学制」「税制」「体制」
⑤ つくる。「制作」
熟語：制限（せいげん） 規制（きせい） 強制（きょうせい） 制度（せいど） 体制（たいせい） 統制（とうせい）
例文：
1. 速度を制限する必要がある。— 需要限制速度。
2. 新しい制度が導入された。— 引入了新制度。
来源：https://www.kanjipedia.jp/kanji/0003857100
```
