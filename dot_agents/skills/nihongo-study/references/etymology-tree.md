# 語義樹・語源テンプレ（etymology-tree.md）

全フロー共通。目標は「なぜ同じ語にこれらの意味があるか」を説明すること。意味の列挙禁止。

## 1. 出力順（固定）

1. `核心一句话`：中文一句，如「番=輪到誰/第几轮」。日语关键词附读音。
2. `語源`：汉字本义 / 古日语义 / 汉文影响 / 社会使用 → 现代。必须分级：
   - `[確定]` 字书/辞书明记
   - `[通説]` 学界多支持
   - `[諸説]` 有争议，并列他说
   - `[助記]` 仅助记联想，明确不是史实
   未fetch到写`—`，不编。
3. `語義樹`：ASCII/Markdown树，每个箭头写一句「为什么这样变」。例（番，形式见本，禁止照抄；番茶/番傘按验证结论处理）：
```
交替・輪番（当番・輪番・交番）[確定]
 ↓ 誰に順が来たか → 順序（順番・当番）
 ↓ 一番・番号・番付 [確定]
 ├─ 当たる人 → 番人・門番・店番 [確定]
 ├─ 順に組む → 番組・番付 [確定]
 ├─ 番茶・番傘「粗・下級」→ 別枝，与輪番直系关系弱 [諸説]，俗说晩茶転/番外未证，不写確定
 └─ 番い（つがい）→ 和語つがふ当て字，与汉语引申无关，另列 [確定]
```
4. `詞族検証`：每个分支举1-2现代词，格式 `日语（読み）= 中文 + 漢字分解 + 为什么用这个字`。
5. `現代注意`：现代首义是什么；古义是否已固定词汇化/书面化。避免把語源义当常用义。
6. `記憶圧縮`：一句话 + 5行内小树，可由核心推导陌生词为合格。

## 2. 多義語 vs 類義語

- 单词多义（如番）：按上树讲，不列①②③孤立义。
- 类义对（如制限/制約）：树只讲各词核心一句，重点仍进6行对比表。
- 汉字与单词分开：汉字讲字源微调，单词讲国语史引申，不混为一条线。多源就写多源。
