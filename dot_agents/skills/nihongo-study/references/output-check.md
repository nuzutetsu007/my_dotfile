# 输出前自检（output-check.md）

三流程共用。发送前逐项打勾，有一项不过就地改完再发。

## 1. 首行锚定 + 行为禁止

第一行必须是模板标题。不许会话语/复述开头。

- ○ `# 漢字：X` / `# 使い分け：A vs B` / `# 文法：〜X`
- × `了解しました…` × `ざっくり言うと…`（先说结论可以，但标题行必须在第一行）
- 送信前に首行だけ読み返す：`#` で始まらなければ前置きを足さず全文作り直す。
- 添削・書き換え禁止：用户没说"改"就不改原文，只解説。
- 反問禁止：文末疑问句禁止。「お知らせください」「何かあれば」类收尾一律禁止。一次给全。

## 2. 行数

- B（词汇）：表行数 Tier1≥4（含意味核心/搭配或場面/置换判定三行）/ Tier2=6；例句 Tier1≥2 / Tier2=每词2。
- C（语法）：比较表 Tier1≥3项 / Tier2=4-6项；例文 Tier1≥2 / Tier2=3+誤用1。
- A（汉字）：意味编号与 fetch 一致；熟語 6-10；例句 2。
- 全量必含：核心一句话 + 語義樹 + 語源分级 + 記憶圧縮。缺任一按 Tier1 处理并声明。
- 不足时如实声明 Tier1，不硬撑、不撒谎。

## 3. 证据

- `[fetch必填]`（音訓/意味编号/熟語读音/辞书义/来源URL）全部来自本次检索。缺失写 `—` 或「辞書未確認」「检索失败，仅供参考」，不估不编。
- 語源/音史必须带分级 `[確定]/[通説]/[諸説]/[助記]`。无分级=不合格。`[助記]`必须明示非史实。
- 丸写し自检：搭配/例句/語義樹与 Skill 示例雷同≥2 处，重写。

## 4. 正字法门禁

- 日语用新字体/常用汉字。×压制 → ○圧制；×数值 → ○数値；×主觀 → ○主観。
- 日语句只含日语字符+日式标点，不许混英文单词。×速度を制限する highway が多い → ○速度を制限する高速道路が多い。
- 中文一律简体。×计画/制約（中文语境） → ○计划/制约。
- 訳は中国語：中文对照不许写英文。×cross a mountain pass → ○翻越山口。
- 假名无误：×予算の制約を受ける（对） vs ×よさん（平片假名混用注意：外来语才用片假名）。

## 5. 来源

- URL 必须来自本次 websearch/webfetch 返回的真实链接，1-3 个。
- 出版社/书名不编：×苳屋書房新辞記 → 写实际看到的署名， `@`不确定不写。
