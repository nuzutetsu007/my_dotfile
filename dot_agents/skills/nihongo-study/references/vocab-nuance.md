# 流程B：类义词ニュアンス比较（vocab-nuance.md）

目标：JLPT 词汇辨析题（語彙・言葉の使い分け）对策。

## 步骤

1. 先各给辞书义一行 `[fetch必填]`（goo辞書 / weblio / kotobank / 日本語NET使い分け优先），注明出处感。查不到不编，写「辞書未確認」。
2. 单词多义（如番/ところ）：先读 `references/etymology-tree.md` 按树讲，不列孤立①②③；类义对仍进对比表，各词核心只给一句。
2. 再进对比表。Tier2 固定 6 行，不许省略任何一行：
   - 意味核心（一句话）
   - ニュアンス（主观/客观、好坏、硬软）
   - 使用場面（书面/口语、法律/日常、上下关系）
   - コロケーション（各 3-4 个典型搭配，带假名）
   - 置换判定（○可换 / △语感变 / ×不可，举一例）
   - JLPT陷阱（出题人爱考的点）
3. 例句：Tier2 每词 2 句（日语 + 中文一行），例句必须体现上面搭配；Tier1 允许每词 1 句，但须声明。
4. 末尾 `覚え方` 一句话 `[可模型知识]`（中文可）。
5. 下の例は形式見本。丸写し自检：你的搭配/例句若与下例雷同（≥2 处相同），判不合格，必须重查重写。

## 例（制限 vs 制約・形式見本。丸写し禁止）

```markdown
# 使い分け：制限 vs 制約
結論：制限=数量・行動に上限を設ける；制約=自由を縛る条件・前提。（中文：限制管“上限”，制约管“束缚条件”。）
| 観点 | 制限（せいげん） | 制約（せいやく） |
| 意味 | 上限を設けて抑える | 条件が自由を縛る |
| 場面 | 法律・規則・数量，硬 | 契約・理論・前提，硬 |
| 搭配 | 速度を制限する／入場を制限する／制限時間 | 時間の制約／予算の制約を受ける／制約条件 |
| 置换 | ×予算の制限（不自然） | ○ |
| JLPT | 数量词后多选制限 | 条件・前提语境多选制約 |
例文：
1. 速度を制限する必要がある。— 需要限制速度。
2. 予算の制約で計画を変更した。— 因预算制约变更了计划。
覚え方：数に上限=制限、自由に足かせ=制約。
```
