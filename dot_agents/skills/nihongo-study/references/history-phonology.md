# 音史・古日語テンプレ（history-phonology.md）

全量回答必填，但压成3-5行，不堆无关历史。fetch不到写`—`。

## 1. 必含要素（有则写，无则省略并说明）

- 漢字音：呉音/漢音/慣用音区分。例：番=バン慣用[確定]，ハン・ハ表外，ホン无据写`—`（已验证，不补）。`[fetch必填]`，无据写`—`。
- 和語音变：連濁・音便（イ/ウ/撥/促）・ハ行転呼（p→ɸ→h）・上代特殊仮名遣い（甲乙类）・歴史的仮名遣い。只写与本词直接相关的一条。例：番有連濁（一番イチバン・番付バンづけ），音便`—`。
- 時代标签：上代/中古/中世/近世/現代。语法必须给古典来源，无据写`—`（例：につき←付く連用+き未确认，写`—`不写確定）。
- 古今注意：現代首义 vs 古义，是否已词汇化/书面化。

## 2. 文法史写法（C流程用）

格式：`古典形 → 音/形变化 → 現代形（理由一句）`。例：`につき②単位：付く「付着・随行」→ 連用中止+き → 每…` `[通説/諸説]`。多说并列，不并单线。
