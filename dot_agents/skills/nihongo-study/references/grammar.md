# 流程C：查语法（含相关比较，必须项）（grammar.md）

## 步骤

1. 识别目标句型 + 推定 JLPT 级别 + レジスター（一句话：硬/书面/告知/口语不可等）。
2. `接続` 单独一行，形式固定（如 `N+につき` / `V辞書形+べからず`）。
3. 用法按编号拆（①②…），每个用法：日语一句话 + 例文1 + 中文一行。多个用法不许混讲。多义语法（如ところ）先读 `references/etymology-tree.md` 给母义→子义一句话，再分用法。
4. 历史层必读 `references/history-phonology.md`：给 `古典形 → 变化 → 現代形` 一行 + `[確定/通説/諸説]` + 時代标签。
4. **関連文型比較表（必须）**：Tier2 为 4-6 项，列固定：
   `文型 | 接続差异 | フォーマル度 | 口语可用？ | 意味重心 | 互换○×△+一例`
   Tier1 允许降为 3 项，但须声明少了哪类。
5. 例文 Tier2 为 3 句（覆盖各用法）+ 誤用 1 组（×→○）+ 覚え方一句话 `[可模型知识]`；Tier1 允许例文 2 句。
6. 数据源 `[fetch必填]` 优先：日本語NET > N1et > Bunpro > maggiesensei。末尾附本次检索到的真实链接；检索失败写「检索失败，仅供参考」，不编 URL。

## 关联项选取规则

- 理由类：ため / ので・から / ばかりに（=普通形+ばかりに。×N+のばかりに） / おかげで 中选2
- 同形多义：该句型的另一用法单独成行（如につき②単位）
- 近形：形近易混（如について / にあたり / ごとに）选1-2
- 凑满 4-6 项，不够从 JLPT 同级找。实在凑不满按 Tier1 输出 3 项 + 声明。
- 本例同样是形式見本：搭配/例句与下例雷同（≥2 处相同）即重写。

## 例（〜につき・形式見本。丸写し禁止）

```markdown
# 文法：〜につき（N2・硬・告知/掲示）
接続：N+につき
意味：①理由「〜のため、〜という理由で」②単位「〜ごとに、〜につき」
| 文型 | 接続 | 口语？ | 重心 | 互换 |
| につき①理由 | N+につき | × | 告知，硬 | ◎ 私有地につき立入禁止 |
| ため | N+のため | ○ | 中性原因 | ○，但告知感弱 |
| ので/から | 普通形+ | ○ | 日常口语 | × 看板不可 |
| につき②単位 | N+につき+数量 | × | 每… | × 不同用法（一人につき1個） |
| について | N+について | ○ | 关于，无原因义 | × |
| にあたり | N/V辞+にあたり | × | 值此…之际 | × |
例文：
1. 雨天につき中止します。— 因雨天中止。
2. お一人につき一枚限りです。— 每人限一张。
3. 工事中につき通行止めです。— 因施工禁止通行。
誤用：×ここは駅につきたばこは吸えませんよ（对人说话太硬）→ ○ここは禁煙です／駅のため…
覚え方：看板・掲示の硬い「ため」=につき；数が出たら単位用法。
```
